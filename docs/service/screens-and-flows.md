# RecipeWeave 画面と操作の一覧

Dev v0.1 の画面と操作の一覧です。2026年9月6日現在、実装済み・公開待ちです。主要ナビゲーションは「ホーム／冷蔵庫／献立／保存」の4つです。設定とヘルプはホームから開きます。検索条件には人数・分量を置きません。将来の画面や部品見本は下表で区別します。

## 主な操作のつながり

| 目的 | 操作の順番 | 終わったときの状態 | 間違えた場合 |
|---|---|---|---|
| 一品を探す | ホーム → 食材を押す → この2つで探す → 料理を開く | 材料と手順が見える | 戻ると食材の選択を保持 |
| 手持ちを使う | 冷蔵庫 → 食材を選ぶ → 選んだ食材で探す | 手持ちと必要量を比べられる | 数量不明は確認待ちのまま続行 |
| レシート登録 | 冷蔵庫 → レシートから追加 → 撮影／画像 → 読み取る → 候補確認 → この内容で登録 | 選んだ食品だけが登録済み | 確定前キャンセル、確定後取消 |
| 読取誤りを直す | 候補確認 → 修正／食材を選ぶ → 名称／数量訂正 → 確認して戻る | 修正した候補に変わる | 誤除外は除外した行から選択して食材指定。読取自体の欠落は後から手入力 |
| 二重登録を防ぐ | 再読取 → 登録済みの可能性 → 履歴を照合 | 同じ購入の再登録をやめられる | 別の買い物なら確認して続行 |
| 量を変えて作る | 料理詳細 → 人数／各材料の数量を直接変更 → この料理を作る | 選んだ量で工程を確認 | 元の分量に戻せる |
| 献立で買い物 | 料理詳細 → 献立に追加 → 買い物リスト | 必要量と手持ちを確認 | 献立の料理変更で再計算 |
| 献立を作る | 献立 → 段取りを見る → 調理を始める → 次へ → 使用量確認 → 完了 | 初期は在庫変更なし。希望時だけチェックして更新 | ホーム上部／献立から再開、戻るで前工程、反映不可の理由表示 |
| 登録を取り消す | 冷蔵庫 → レシート履歴 → 今回の登録を取り消す → 残量確認 → この内容で取り消す | 未消費残量だけ消え、履歴は取消済み | 編集済みは現在量と変更前後を確認。以前の在庫・消費履歴は保持 |
| 別端末へ移す | 設定 → データを書き出す → 移動先でデータを読み込む → 件数と置換対象を確認 | 移動先をファイル内容に置換 | 不正ファイルなら無変更。先に移動先も書き出せる |

## 表示上の約束

- 未選択の食材にも空のチェックを置く。選択済みはチェックと枠で示す。冷蔵庫行の「編集」は選択を変えない。
- 冷蔵庫が空なら、検索・手入力・レシート登録の入口を示す。
- 「数量不明」「量を確認」「買い足し」は意味が異なるため、同じ表示にしない。
- 候補の確認と、在庫への登録完了を明確に分ける。
- 保存や登録が失敗した場合に成功表示を出さない。
- サンプル画像・サンプル料理・サンプル読取結果には、そのことを表示する。
- 同期を使えない環境で「同期済み」と表示しない。
- 小さな文字リンクだけに重要操作を置かず、主操作は押しやすい領域で表示する。
- 元画像・読取全文・店舗名・購入日時は残さない。登録日時と登録食品、重複・取消に必要な識別情報と状態履歴だけを残す。

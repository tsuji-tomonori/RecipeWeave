# RecipeWeave サービス概要

文書状態：利用者の使い方を確認するためのサービス草案。以下の「目指すサービス」と「現在試せる範囲」を区別します。画面上の料理・時間・分量は試作用の例を含みます。

## 何ができるサービスか

RecipeWeaveは、食材を選ぶところから、料理を決める、買い物をまとめる、順番に作るところまでをつなぐサービスです。「鶏肉とキャベツで何を作ろう」「冷蔵庫にあるものから決めたい」「いつもと違う一品も見たい」というときに使います。

名前を入力しなくても、食材の写真を押すだけで料理を探せます。トップの食材には、選ぶ前から空のチェックボックスを表示します。人数と分量は料理を決めた後に変えられるので、検索時の入力は不要です。

買い物の後は、レシートを撮るか保存済みの画像を選びます。読み取った食品を候補として表示するので、間違いだけを直してまとめて冷蔵庫へ登録できます。自動で候補を作りますが、利用者が「この内容で登録」を押すまでは在庫を変更しません。

## 大切にする使い心地

| 方針 | 利用者にとっての動作 |
|---|---|
| すぐ選べる | 食材カード全体を押して選択。チェックと枠で選択済みが分かる |
| 入力を後回しにできる | 冷蔵庫は食材名だけで登録できる。数量の登録は任意 |
| 次の操作が分かる | 画面下に大きな主ボタンを置き、次に進む操作をそろえる |
| 戻ってもやり直さない | 食材の選択、検索条件、調理中の工程を保つ |
| 間違いを直せる | レシートの読み取り結果を直せる。登録後も履歴から取り消せる |
| いつもと違う料理に出会える | トップに「偶然の一品」。同じ食材のアレンジも比較できる |
| 数量を断定しない | 数量不明・換算できない在庫は、そのまま「量を確認」と表示する |

## 主な使い方

| したいこと | 最初に開くところ | 得られる結果 |
|---|---|---|
| 食材から料理を決める | ホーム | 選んだ食材を使う料理候補 |
| 手持ちを使い切る | 冷蔵庫 | 使いたい食材を優先した候補 |
| レシートから在庫を入れる | 冷蔵庫 → レシートから追加 | 確認した食品を一括登録 |
| 同じ材料で変化をつける | 料理詳細 → アレンジ | 味付けや追加材料の異なる候補 |
| 複数の料理をまとめる | 献立 | 料理ごとの分量、買い物、調理順 |
| 手順を見ながら作る | 料理詳細 → この料理を作る／献立 → 段取りを見る | 大きな文字で一工程ずつ確認 |
| 気に入った料理を残す | 保存 | 後で開ける料理一覧 |

「冷蔵庫」は冷蔵品に限りません。冷凍食品、常温の食材、即席食品、惣菜も、保存場所を分けて管理します。

## 目指すサービスと現在試せる範囲

公開ページに表示する「試用版でできること」を、実際の提供状態に合わせて更新します。できない操作を、完了したように表示しません。

| 項目 | 目指すサービス | Dev公開時の説明に必要な確認 |
|---|---|---|
| 料理検索 | 公開済みの料理から探す | 8品のサンプルで提供予定。検索対象を明記 |
| レシート読取 | 利用者の画像から候補を作る | この端末内での日本語読取を実装予定。動作確認後に実提供と明記 |
| 冷蔵庫・保存・献立 | 続きから使える | この端末だけに保存する機能を実装予定。保存範囲を明記 |
| データの持ち出し・復元 | 書き出したデータを戻す | ファイル内容で現在のブラウザを置換。件数と対象を確認し、不正なら無変更 |
| 別端末への引継ぎ | ログインして同期 | 今回の試用版では未提供。今後の機能として区別 |
| 調理ガイド | 図・文章・提供済み動画で確認 | 見本の図か、再生できるガイドかを明記 |
| 通知・タイマー | 調理の経過を確認する補助 | 画面を閉じたときの動作や音の条件を明記 |

この文書だけで、画像読取や同期がすでに使えるとは判断できません。提供状況は公開ページと利用者向けマニュアルの冒頭を正本にします。

## 食材とレシピの扱い

- 登録数や将来の目標件数ではなく、実際に選べる料理を表示します。
- 同じ料理の人数違いを別レシピとして並べません。
- レシートの「198円」を「198g」に置き換えません。
- 「1パック」は購入した単位として扱い、内容量が分からなければグラム数は不明のままにします。
- レシートから賞味期限や消費期限を推測しません。期限を登録する場合は食品の表示を確認します。
- 食べられない食材の設定は、検索と偶然の一品に共通で使います。加工食品の原材料が確認できない候補を「除外済み」と断定しません。
- 料理を見たり買い物にチェックしただけで、在庫を減らしたり増やしたりしません。利用者が確認した操作で変更します。
- 完了時の「在庫から使用量を引く」は最初はチェックなしです。希望した場合だけ、同じ単位で十分な量のある材料を減らします。
- レシートの取消は、その登録の未消費残量だけに適用します。以前からの在庫や使った履歴は残し、取消済みは再取消できません。
- 試用版は画像を端末内で読み取り、画像・全文・店舗名・購入日時を残しません。選んだ食材と登録日時、重複・取消に必要な履歴をこのブラウザに保存します。

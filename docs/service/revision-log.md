# 利用者文書のレビュー反映記録

対象：初心者レビュー `novice-review.md`、レシート・在庫レビュー `receipt-review.md`。

この表は指摘への変更記録です。独立した再レビューの合格記録ではありません。実装の成功を示すものでもありません。

## Dev v0.1 への説明更新（2026年9月6日）

利用者向け文書を、確定したサービス草案から「実装済み・公開待ち」の説明へ更新しました。公開ページは初期設定待ちで、未公開です。食材選択、8品の検索、人数・材料量、レシート確認・取消、端末保存、献立・買い物・調理の操作は実装と照合しました。半月切り・くし形切り・角切り・ざく切りは図と文章、タイマーは終了時刻の保持として説明し、動画・画面外の音通知・端末間同期は未提供としています。

保存に必要な Web Locks が使えない場合は保存できないことを manual と FAQ Q41 に追加しました。破損保存からは正常なバックアップを明示確認して復旧し、正常な保存や異なる版を破損扱いで強制上書きしないことも、実装済みの挙動として追記しました。新しい操作仕様は追加していません。

開発側から共有された検証結果はフロントエンド31テスト、Svelte型検査・ビルドの成功です。テストは数量・状態計算と疑似DOMの操作検査です。Node上の日本語OCRエンジンの局所確認では生成UI画像から195文字（日本語77文字）を認識しました。これらは実ブラウザ・実レシートの一般精度・実利用者評価・AWS実配備の受入を示しません。対象版と実行結果の正本は `docs/verification/service-dev.md` です。

## データの例で取り消し結果を確認する

以前からの在庫を500g、今回レシートの追加を300gとした場合の説明は次のとおりです。以前の500gはすべての場合で変更しません。

| 今回登録分の状態 | 取消前に示す内容 | 確定後 |
|---|---|---|
| 未変更の300g | 現在300g → 0g | 今回の300gだけを除去 |
| 今回分から100g使用済み | 使用100g、現在200g → 0g | 未消費200gだけ除去。使用100gの履歴は維持 |
| 今回分を250gに編集済み | 登録300g、編集後250g → 0g | 編集した現在量を明示して確認後に除去 |
| 今回分が使用済み／削除済み | 現在残量なし | 他の在庫を減らさず取消済みを記録 |
| 今回分の量が不明 | 数量不明の登録項目を削除 | gを推測せず、今回の不明項目だけ除去 |

今後クラウド同期を提供するときも、この試用版の端末保存を同期済みのデータへ読み替えません。実際の移行方法・保存先・削除範囲を改めて説明します。
